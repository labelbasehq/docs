On each release page you will find release tracks. By default you will not have any tracks in a release. Artists, manager etc. will be in charge to add them to the release using the portal. (See portal section of the documentation).

![Capture D’écran 2026 01 13 À 15 29 12](/images/Captured’écran2026-01-13à15.29.12.png)

On each track you will have the following informations.

- title of the track
- audio of the track
- format of the track
- genre of the track
- BPM
- key
- artists
- Date of reception
- more
  - Split management
  - Create independant release (in case you want a single of an album to be a release before the album release)
  - Add to playlist

<Info>
  Informations like BPM, Key and genre are computed using our AI.

  Our AI is not a public model. We are owning our own server and the data parsed are protected and not exposed to public models.

  See the AI section of the documentation.
</Info>

# Track versions

Track versionning is an important notion.\
Sometimes artists will send to you an unfinished version of the track, or a simple mix, or just stems.

Here you can upload any version as you want and assign it to the track so the artist will have the opportunity to listen it and to give you feedback using the chat.
