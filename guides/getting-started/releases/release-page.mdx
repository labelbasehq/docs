# Updating infos

You will find a bar of different actions 

![Capture D’écran 2026 01 13 À 15 23 09](/images/Captured’écran2026-01-13à15.23.09.png)

Using this bar, you can update :

- Artist assigned to the release
- Release type (EP, Single, Album, Compilation...)
- Release Date
- Release Owner (The person in your workspace in charge of this release)
- The label of the release
- Members of the release (In case you want to invite the manager, other artists etc...)

## Clicking on ...more 

![Capture D’écran 2026 01 13 À 15 25 43](/images/Captured’écran2026-01-13à15.25.43.png)

By clicking on more you will find more actions :

- Updating metadata 
- Add to a playlist 
- Downlaod all assets
- Cancel a release
